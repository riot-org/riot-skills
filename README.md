# Riot Skills

Riot 的技能目录。每个子目录是一个 skill，入口是里面的 `SKILL.md`。

| Skill | 介绍 |
| --- | --- |
| [video-production](./video-production) | 用代码做视频：定目标、写分镜、动效与转场、配乐卡点、旁白字幕，再渲染质检。画面用 HTML 时间轴逐帧渲染，也可以用 ffmpeg 剪已有素材。 |
| [moss-tts](./moss-tts) | 把文字转成语音，用于视频旁白、有声内容和播报。走 Moss TTS，可挑选音色、控制停顿。 |
| [a-share-research](./a-share-research) | 中国 A 股交易研究，前提认知是 A 股属于融资型市场。含市场状态识别、候选股筛选、持仓复盘和量化策略研究，结论以图表和报告呈现。 |
