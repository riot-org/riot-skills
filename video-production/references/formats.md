## 各类型的默认转场

先按这张表定好全片转场，再写分镜。每种转场的用法和元素进场时刻见 transitions.md。

| 类型 | 默认转场（占大多数） | 段落切换 | 高潮 / 重音 |
|---|---|---|---|
| 产品宣传片 | crossfade | fadeThrough、wipe-right | flash（1–2 次） |
| 功能演示 / 教程 | crossfade | push-left（步骤之间） | 不用 |
| 数据故事 | crossfade | push-up（下一个数据） | 不用 |
| 竖屏短视频 | cut（卡点） | zoom | flash |
| 照片 / 活动回顾 | crossfade（0.6–0.8s） | fadeThrough | 不用 |
| 片头 / Logo 演绎 | 单场景，不需要转场 | — | — |
| 文字动画 | cut 或 crossfade | blur | flash |

## 通用节奏规律

| 项目 | 取值 |
|---|---|
| 单个镜头 | 1.5–4 秒；纯文字镜头按阅读时间算 |
| 文字阅读 | 中文 5–7 字/秒，英文约 3 词/秒，另加 0.5 秒 |
| 列表类镜头（功能、要点） | 每项 2–3 秒，同一列表等间隔，方便卡拍 |
| 转场 | 0.3–0.6 秒，占镜头时长的 15–25% |
| 结尾停留 | 2–3 秒 |
| 总时长 | 社交短视频 15–30 秒；宣传片 30–60 秒；讲解 60–180 秒 |

结构上，大多数视频都是**钩子 → 铺垫 → 主体 → 高潮 → 收尾/行动**。区别在各段的比例。

## 产品宣传片（30–60 秒，16:9）

| 段落 | 时长 | 做法 |
|---|---|---|
| 开场 | 4–6s | Logo 弹入 → 产品名大字 → 一句定位 → 一个技术或卖点标签。深色背景有仪式感 |
| 全貌 | 5–7s | 真实界面截图放进窗口框，3D 翻起入场，再慢慢推近最有信息量的区域 |
| 差异点 | 3–4s | 一个和竞品不同的点，用一组标签依次弹出，或用一组对比 |
| 金句转场 | 2–3s | 一句短话，超大字，配音乐重音 |
| 功能轮播 | 每项 2.4–2.5s | 左文右图（竖屏改上图下文），底部进度条；标题一句加说明一句 |
| 信任点 | 4–5s | 用一个小交互演示（光标点击 → 状态变化 → 结果出现），比列要点更有说服力 |
| 结尾 | 4–5s | Logo、名字、定位、平台、网址，停住 |

深浅场景交替能让段落自然分开。

## 功能演示 / 教程讲解（60–180 秒）

- 开头 3 秒说清「看完你能做到什么」，展示最终效果。
- 按步骤分段，每步一个编号标题卡（1–1.5 秒），接着是操作画面。
- 录屏要处理：裁掉无关区域，放大到操作区域（推镜头），光标点击处加圆圈涟漪，等待加载的片段 2–4 倍速或直接剪掉。
- 每步有一行字幕说清当前在做什么；关键参数、命令用等宽字体放大标注。
- 结尾回到最终效果，加上下一步（文档链接、下载）。
- 有旁白时，画面跟旁白走：旁白说到哪，画面高亮到哪。

## 数据故事（20–60 秒）

- 一个镜头一个数据结论，标题直接写结论（「三年翻了四倍」），而不是写指标名（「营收趋势」）。
- 数字用滚动计数（count-up），0.8–1.5 秒，`easeOut`。
- 图表分步出现：先坐标轴，再数据（折线按路径长度描出，柱子从基线长出），最后高亮关键点和注释。
- 颜色克制：一个强调色给要说的那条线或柱，其余灰色。
- 注明数据来源，放在角落，小字。

## 竖屏短视频（9:16，15–30 秒）

- 第 1 秒就要有冲突、问题或结果；不要片头。
- 默认静音播放：所有关键信息都要有画面文字，字幕放大（1080 宽时 48–64px），带底色或描边。
- 避开平台 UI：顶部 ~12%、底部 ~20%、右侧 ~15% 会被按钮、标题、评论区挡住。
- 节奏更快：镜头 1–2 秒，每 3–5 秒要有新的视觉变化。
- 结尾引导关注、评论或「看主页链接」，文字停留 2 秒以上。
- 小红书偏好 3:4（1080×1440）；抖音、视频号、Reels、Shorts 用 9:16。

## 照片 / 活动回顾（30–90 秒）

- 选片：开头和结尾用最强的两张；中间按时间或情绪排序，同类照片别挨着放。
- 每张 1.5–3 秒，配 Ken Burns（缓慢推拉 3–8% 加平移），推拉方向交替。
- 卡在音乐节拍上切换；高潮段可以每拍一张。
- 竖横混排时，用模糊放大的同一张图垫底，避免黑边。
- 插 2–3 张文字卡（时间、地点、一句话），节奏上像换气。
- 配乐偏温暖，见 audio.md 的情绪对照。

## 片头 / Logo 演绎（3–8 秒）

- 一个动作讲完：拼合、描边生长、遮罩揭示、粒子聚合，选一个，别堆砌。
- 有预备动作（先轻微收缩或停顿）再展开，落定时轻微过冲，然后静止 1 秒以上。
- 配一个音效重音（低频冲击加混响尾巴），落在 Logo 定格那一帧。
- 同时导出透明背景版本（WebM VP9 带 alpha 或 PNG 序列），方便用户叠到别的视频上。

## 文字动画 / 金句海报（5–20 秒）

- 按意群分行，一次出一行或一个词；重点词放大、换强调色。
- 每个词 0.15–0.3 秒入场，按语速错峰；整句完整后停留到够读两遍。
- 字体最多两种，一种做主角。
- 可以按配乐的拍子出词，非常有节奏感。

## README / 文档里的 GIF（3–10 秒）

- 只演示一件事，循环播放，首尾画面一致，循环才不跳。
- 宽 800–1200px，12–15fps，用调色板优化（配方见 ffmpeg-recipes），控制在 5MB 以内。
- 不需要声音，不需要片头片尾。
