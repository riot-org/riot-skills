## 缓动

`M.ease` 里有现成的缓动（用法见 motion-api.md）：

| 函数 | 用在哪 |
|---|---|
| `easeOut`（三次） | 默认。入场、元素落定：快速出现、缓慢停下，显得利落 |
| `easeInOut` | 场景淡入淡出、镜头推拉、从 A 移到 B |
| `back`（轻微过冲） | 弹出类：Logo、标签、按钮、图标。过冲后回弹显得有弹性 |
| 线性 | 只用在匀速的东西上：进度条、滚动字幕、时钟 |

别全片都用同一种缓动，也别为一个元素换着用；一类动作对应一种缓动。

## 时长

| 动作 | 时长 |
|---|---|
| 小元素入场（标签、图标、单行字） | 0.4–0.6s |
| 大标题、卡片、截图入场 | 0.7–1.2s |
| 场景交叉淡入 | 0.35–0.5s |
| 镜头慢推 | 2–4s（持续整个镜头） |
| 数字滚动 | 0.8–1.5s |
| 打字机 | 12–20 字/秒 |
| 闪屏转场 | 0.3–0.4s |

大的东西动得慢，小的东西动得快。

## 入场与退场

- **上浮淡入**：位移 40–60px + 透明度 + 模糊 8px→0。最通用。`M.enter(el, lt, at, "rise")`。其余手法对应的预设见 motion-api.md「入场预设一览」。
- **缩放进入**：大字从 1.1–1.3 缩到 1，同时去模糊，有「砸下来」的力量感。
- **弹出**：从 0.4–0.7 缩放到 1，用 `back`。适合小而重要的元素。
- **3D 翻起**：`perspective(2400px) rotateX(28deg→0) translateY(400px→0)`，适合截图、窗口、卡片。
- **遮罩揭示**：用 `clip-path: inset()` 从一边擦出，适合标题、图片。
- **描边生长**：SVG `stroke-dasharray/stroke-dashoffset`，适合图标、折线图、Logo。
- 退场比入场快一点（约 60%），或者干脆随场景整体淡出，不用每个元素单独退。

## 错峰

- 同组元素间隔 0.07–0.12s 依次入场：标题 → 副标题 → 正文 → 按钮。
- 网格或列表按阅读顺序错峰（从左到右、从上到下）。
- 错峰总时长控制在 0.6s 内，否则观众会等。

## 转场

> 转场的选择、参数、元素进场时刻和常见错误都在 **transitions.md**，那里是准的。下面只是原则。

- **交叉淡入**：默认，最安全，前后场景重叠 0.35–0.45s。
- **推移**：两个场景一起平移，适合同一主题的连续页面（如功能列表）。
- **共享元素**：上一个场景的某个元素（Logo、卡片）变形、移动成下一个场景的元素。最高级，最连贯。
- **色块闪屏 / 擦除**：品牌色全屏闪 0.3s 或色块擦过，配音乐重音。全片最多两三次，否则廉价。
- **匹配剪辑**：前后镜头的形状、位置、运动方向一致，硬切也很顺。
- 一部片子用一两种转场方式就够了。

## 镜头运动

- **Ken Burns**：图片在显示期间缓慢放大 3–8% 并轻微平移。推拉方向在相邻图片间交替。
- **推近**：从全貌推到细节（截图 1→1.5 倍，`transform-origin` 设在要看的区域），引导视线。
- **视差**：前景、中景、背景按不同速度平移（如 1 : 0.6 : 0.3），制造纵深。
- **轻微漂移**：整体极慢地平移或旋转（0.5° 以内），让静止画面有呼吸感。
- 镜头运动和元素运动别同时做太多，观众不知道看哪。

## 排版

1080p 下的参考字号（竖屏 1080 宽时再放大 10–20%）：

| 层级 | 字号 |
|---|---|
| 超大金句 / 产品名 | 150–260px |
| 场景标题 | 64–120px |
| 副标题 | 40–60px |
| 正文 / 说明 | 26–34px |
| 标签、代码、角注 | 22–28px |

- 每屏不超过 3 个层级；正文最多两行。
- 中文标题字重 700–800 就够了，字距略收（-0.02em）。
- 中英混排：西文字体在前，中文字体（PingFang SC / 思源黑体）在后做回落。
- 数字、代码、网址用等宽字体，显得精确。
- 视频字幕和画面文字要比网页大得多，手机上看会再缩小一半。

## 颜色与背景

- 有品牌就用品牌色变量；没有就选一个强调色，加上一套近黑、近白、2–3 级灰。
- 强调色只给最重要的一个元素：关键词、按钮、要看的数据。
- 深浅场景交替，可以把段落分开；连续三个以上同色场景会显得平。
- 背景别纯平：浅色加极淡网格或噪点，深色加径向渐变或轻微光晕。
- 文字压在图片上时加暗角、渐变遮罩或底板，保证对比度（至少 4.5:1）。

## 安全区与尺寸

| 用途 | 尺寸 |
|---|---|
| 横屏 16:9 | 1920×1080（4K 用 3840×2160，渲染慢 4 倍） |
| 竖屏 9:16 | 1080×1920 |
| 小红书 3:4 | 1080×1440 |
| Instagram 帖子 4:5 | 1080×1350 |
| 方形 1:1 | 1080×1080 |

- 通用：重要内容离边缘至少 5%。
- 竖屏平台：顶部 ~12%（状态栏、标题）、底部 ~20%（文案、进度条）、右侧 ~15%（点赞评论按钮）尽量别放关键信息。
- 横竖屏要各自排版，不能只缩放：横屏左右分栏，到竖屏改上下堆叠。

## 让画面不「死」

- 任何镜头都要有东西在动：Ken Burns、光晕缓慢呼吸（`sin(t)`）、背景漂移、进度条走动。
- 静止的停留镜头上至少有一个慢速运动。
- 列表类内容加进度指示（点、条），观众知道还有多少。
- 演示交互时用假光标：移动用 `easeInOut`，点击时缩到 0.85 再回弹，被点的元素同时给反馈。

## 常见廉价感来源

- 所有元素同时动，或者全是线性运动。
- 转场花样太多（旋转、翻页、马赛克轮着用）。
- 字太多、字太小、停留太短读不完。
- 颜色太多，强调色到处都是。
- 素材模糊：截图要用 2 倍图，SVG 优先。
- 结尾太短，名字刚出来就黑了。
