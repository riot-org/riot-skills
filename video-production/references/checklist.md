# 检查清单

每轮修改后运行 `render.cjs video.html --check`，用 Read 打开 `check.png`，逐项检查。有一项不通过就改，改完重新 `--check`。全部通过后再整片渲染。

## 怎么看 check.png

- **第一部分「各场景静止帧」**：每个场景在离开转场开始前一刻的画面，此时这个场景的所有元素都应该已经到位。
- **后面每一行是一个转场**：0%（转场开始）、25%、50%（分界点）、75%、100%（转场结束）。

## A. 静止帧（每个场景都要过一遍）

- [ ] 所有元素都完整显示：没有半透明、没有残留模糊、没有还在半路的元素。
- [ ] 文字没有溢出容器、没有被画面边缘裁掉、没有和其他元素重叠。
- [ ] 中英文混排的标签、按钮里文字垂直居中（不居中就加 `line-height: 1.2`）。
- [ ] 一屏只有一个视觉焦点；最大的字就是最重要的信息。
- [ ] 文字和背景对比清晰（浅底深字、深底浅字；压在图片上的字有遮罩或底板）。
- [ ] 重要内容离画面边缘至少 5%；竖屏版避开顶部 12%、底部 20%、右侧 15%。
- [ ] 图片清晰，没有被拉伸变形。
- [ ] 常驻元素（角落 Logo、字幕）颜色和当前背景搭配（深底用浅色）。
- [ ] 字幕：放得下一行的就是一行；折行的两行长短接近；全片字幕文本里没有手写的 `<br>`（`grep -n "<br" video.html` 只该命中正文排版，不该命中 CAPTIONS）。

## B. 转场（每个转场都要过一遍）

- [ ] **0% 帧**和上一个场景的静止帧基本一样（离开前没有元素提前消失）。
- [ ] **100% 帧**里新场景已经完全占满画面，没有旧场景的残影。
- [ ] **50% 帧**：
  - crossfade：两个场景叠在一起，但不是一片灰（深浅切换时就会灰，应改用 fadeThrough）。
  - fadeThrough / flash：基本是纯色。
  - push / slideOver / wipe / iris：能同时看到两个场景，**新场景那一半不是空背景**。
  - zoom / blur：新场景隐约可见，四周没有露出另一个场景的边框。
- [ ] **75% 帧**：新场景的主体（标题或主图）已经能看到。只看到背景就说明入场太晚（见 transitions.md「新场景的元素什么时候进场」）。
- [ ] 没有任何一帧出现黑屏、白屏的缝隙（fadeThrough 有意过渡的纯色除外）。
- [ ] 没有元素在转场中突然跳位置（多半是 CSS transform 被覆盖了）。

## C. 全片节奏（看 `--timeline` 的输出）

- [ ] 转场种类 2–4 种；flash ≤ 3 次。
- [ ] 相邻两个转场没有连续都是 push / zoom / flash / wipe。
- [ ] 每个场景至少 3 秒（列表轮播的单项除外，至少 2.2 秒）。
- [ ] 结尾场景至少 4 秒，最后 2 秒画面静止。
- [ ] 深浅背景交替，没有连续三个同色场景。
- [ ] 全片总时长符合目标平台（formats.md）。

## D. 动态细节（用 `--stills` 抽几帧大图，或在浏览器里按空格逐段看）

- [ ] 同一场景的元素有先后，不是同时冒出来；错峰总长 ≤ 0.6 秒。
- [ ] 入场方向一致（同一场景里不要一个从左、一个从右、一个从上）。
- [ ] 静止超过 2 秒的场景有慢速运动（光晕呼吸、推拉、推镜头）。
- [ ] 数字滚动、打字机在场景结束前完成，并停留至少 1 秒。
- [ ] 光标移动是先快后慢的曲线，点击后界面有反馈（状态变色、结果出现）。
- [ ] 轮播的进度条和内容切换同步。

## E. 成片（渲染完 MP4 后）

- [ ] `ffmpeg -i out.mp4`：时长对、分辨率对、30 fps、有音频流（有配乐的话）。
- [ ] 用 ffmpeg-recipes「检查拼图」抽 4–6 帧，确认和 check.png 一致（渲染没出错）。
- [ ] 配乐的重音（波形图上的尖峰）落在 flash 转场、大字出现、结尾 Logo 的时刻上。
- [ ] 结尾音乐渐弱，没有被硬切。
- [ ] 整体响度约 -14 LUFS，峰值 ≤ -1 dB（audio.md）。
